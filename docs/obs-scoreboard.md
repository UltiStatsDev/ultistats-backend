# Табло матча в OBS

Откройте `/obs-admin.html` на публичном адресе **backend**, выберите матч или введите его UUID. В разделе «Табло · выбранный матч» настройте короткие названия, цвета и порядок сторон. Пустое название использует исходное название матча, «Авто» выбирает цвет по изображению команды с запасным цветом и автоматическим контрастом текста.

Предпросмотр немедленно показывает ввод, перестановку и сброс. В эфир они попадают только после «Сохранить табло». «Сбросить профиль» возвращает исходные названия, автоматические цвета и исходный порядок в preview; сохраните сброс, чтобы применить его к источникам. Эти настройки принадлежат одному матчу, сохраняются на сервере и не меняют команды, счёт, игровой журнал или оформление Event Log.

Скопируйте «Стабильную ссылку табло» в OBS → Browser Source. Рекомендуемый размер **1000 × 160 px**. Для пропорционального масштаба поддерживаются, например, 500 × 80 и 1500 × 240. При другом соотношении сторон полоса вписывается целиком, свободная область прозрачна. Размещайте и масштабируйте источник средствами OBS. Логотипы вписываются целиком; при отсутствии/ошибке изображения отображаются инициалы. Длинные названия ограничены шириной своей плашки.

Ссылка `/obs-scoreboard.html?matchId=<UUID>` остаётся привязана к этому матчу. Выбор другого матча в настройках не переключает открытые источники. Несколько источников одного матча получают один сохранённый профиль; другие матчи и Event Log работают независимо. Открывайте источники с одного backend origin: существующий SharedWorker разделяет один OBS SSE между вкладками одного browser context. Отдельные browser contexts имеют свои соединения.

До старта видны команды, `0 : 0` и `00:00`. Часы показывают время от фактического старта, включая таймауты и перерыв; после часа — например, `63:12`. После завершения фиксируется фактическая длительность. Разрешённая поздняя коррекция результата обновляет счёт без изменения длительности. Перезагрузка восстанавливает серверные данные.

При обрыве связи последнее табло сохраняется; часы известного IN_PROGRESS продолжаются. После восстановления источник сверяет состояние и останавливает часы, если матч завершился за время обрыва. Причина ошибки и состояние подключения видны в настройках, в эфире диагностического текста нет. При первом открытии неверного/недоступного матча источник прозрачен. Счёт учитывает только принятые сервером события; неотправленные действия Web не учитываются.

## API для интеграции

- `GET /api/v1/obs/scoreboard/{matchId}` — `Cache-Control: no-store`, один согласованный committed snapshot: `matchId`, упорядоченные `teams[{teamId,teamName,photoUrl,score}]`, `status`, nullable `startedAt`/`endedAt`, `serverNow`, `profile`. GET не создаёт профиль. Историческое название берётся из match snapshot, фото — из существующих данных команды.
- `PUT /api/v1/obs/scoreboard/{matchId}/profile` — полная замена `{shortNames: {teamUUID: "Название"}, teamColors: {teamUUID: "#RRGGBB"}, swapped: false}`. `{}` сбрасывает профиль. До двух ключей в каждой карте; ключи принадлежат текущим командам матча, названия непустые, без управляющих символов, до 80 UTF-16 символов; null недопустим. Последнее сохранение побеждает. Профиль существует отдельно от игровых данных.
- Некорректный UUID/профиль — `400`, отсутствующий или удалённый матч — `404`. Настройки без авторизации, как существующий OBS API; используйте тот же доверенный доступ.
- Существующий `/api/v1/obs/stream` дополнен `match-changed` и `scoreboard-profile-changed` с `{matchId}`. Это AFTER_COMMIT invalidation; прочитайте GET заново. `connected` также требует сверки. Scoreboard использует существующие `event-log-changed`/`match-finished` и продолжает слушать завершённые матчи. Старые v1/v2 event API, очередь и терминальные SSE-контракты не меняются.

Миграция V8 добавляет только `obs_scoreboard_profiles(match_id PK/FK, payload TEXT)`. Технические проверки и воспроизводимый synthetic стенд описаны в [tools/obs135/README.md](../tools/obs135/README.md). Общая приёмка требует отдельной проверки настоящего OBS Browser Source и подтверждения QA/PO; Chromium-проверка её не заменяет.
