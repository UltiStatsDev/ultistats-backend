# Послематчевая панель OBS

Браузерный источник и закрытый предпросмотр показывают «Матч завершён» для выбранного матча в статусе `FINISHED`. Панель остаётся на экране, пока выбран этот матч. После скрытия или окончания показа лидеров источник возвращается к актуальной фазе. При смене матча AUTO показывает фазу нового матча.

`postmatch` входит в существующий снимок `/api/v1/obs/sources/infographics/{matchId|auto}` и его закрытый аналог `/api/v1/obs/previews/infographics/{matchId|auto}`. AUTO оборачивает выбранный снимок в `snapshot`. Для остальных статусов `postmatch` равен `null`. Снимок использует ключ `EXACT_INFOGRAPHICS` или `AUTO_INFOGRAPHICS`, а закрытый предпросмотр — штатную сессию сотрудника. Для OBS не нужен отдельный запрос общей статистики.

- `statsAsOfEventAt` содержит время последнего активного события канонического журнала или `null` при пустом журнале.
- `teams` идёт в порядке команд снимка. У каждой команды есть `teamId`, `score`, кольца `accuracy` и `possession` как дроби от 0 до 1, исходное `possessionTimeMs` и шесть числовых полей `metrics`.
- Точность равна отношению точных передач ко всем попыткам. При отсутствии попыток значение равно `null`. Шесть строк показывают точные пасы, неточные пасы, сумму трёх счётчиков блоков, перехваты, кэллаханы и брейки. Для каждой пары своя шкала `max(1, левая, правая)`. Действительный ноль виден как 0 с пустой полосой. Недоступное значение показано прочерком. Если одно значение отсутствует, обе полосы этой строки остаются пустыми.
- Доля владения совпадает с обычной статистикой. Время владения команды делится на суммарное время владения двух команд. Кольцо заполняется по исходной доле, подпись округляется до одного знака после точки, например `33.3 %`. Если обе команды имеют нулевое время, доли равны `null` и панель показывает «Нет данных о владении.». Если время одной команды положительное, нулевое время соперника даёт `0.0 %`.
- Владение считается по существующим правилам от первого до последнего активного события. Время пауз и свободного диска не входит в сумму владения, время после последнего события не добавляется.
