# Команды показа инфографики OBS

На защищённой странице `/obs-leaders.html` выберите AUTO или EXACT, обновите контекст и нажмите «Показать лидеров матча». Кнопка «Скрыть» на странице лидеров относится к текущему показу лидеров. Команды требуют HTTPS, OBS_ADMIN, текущих идентификаторов установки/аккаунта/сессии и CSRF.

## Контракт

- GET `/api/v1/obs/infographics/leaders/{matchId|auto}` возвращает `presentation` с `expectedInputRevision`, `expectedSettingsRevision`, `expectedGeneration`, `activeGeneration` и `canShow`. `canShow` относится к лидерам, `canShowStats` — к итогам выбранного завершённого матча. `activePresentation` содержит текущую квитанцию показа или null, `serverNow` — время сервера для отсчёта. Оба поколения могут быть null. Для пульта `binding` и `matchId` идентифицируют источник, `availability` содержит четыре логических поля `LEADERS`, `ROSTER`, `POINT`, `STATS`. При активной автоматической фазе вместо квитанции возвращается `activePhase` с `kind` (ROSTER или POINT), `origin: AUTO`, `startedAt` и `phaseToken`. У такой фазы нет срока окончания. AUTO сохраняет оболочку `snapshot`. Последнее поколение остаётся основанием для следующей команды после истечения, скрытия или потери актуальности.
- POST `/api/v1/obs/infographics/presentations` принимает необязательный `kind` (LEADERS по умолчанию, ROSTER для ростеров, POINT для состава, STATS для итогов), `binding` (EXACT или AUTO), `expectedMatchId`, три поля `expected*` из `presentation` и UUID `operationId`. Явный null `expectedGeneration` означает первый показ в этом контексте. Ответ 200 содержит `generation`, `matchId`, `startedAt`, `expiresAt` `pageSeconds`, `kind` и `origin` (MANUAL или AUTO). Для STATS поле `pageSeconds` задаёт длительность всего показа.
- Повтор с тем же `operationId` и теми же полями возвращает исходный ответ даже после скрытия или истечения. Для нового показа прочитайте текущий контекст и создайте новый `operationId`. 409 означает конфликт входных данных, поколения, повторное использование идентификатора с другими полями или недоступность запрошенного показа.
- DELETE `/api/v1/obs/infographics/presentations/{generation}` возвращает 204 для текущего поколения, в том числе при повторном скрытии. Старое поколение получает 409.
- POST `/api/v1/obs/infographics/presentations/hide-phase` принимает `binding`, `expectedMatchId`, `expectedGeneration` (включая явный null), `phaseToken` из `activePhase` и UUID `operationId`. Возвращает 204, если фаза по-прежнему активна и привязка совпадает. Смена фазы, смена выбранного AUTO матча или более новая команда дают 409. Идентичный повтор возвращает 204 без изменения эфира.

## Проекция эфира

В защищённом снимке и keyless preview поле `leaderPresentation` содержит актуальное поколение, абсолютные времена, интервал и зафиксированные списки обеих команд либо null. Ключ источника даёт доступ к чтению снимка. Для EXACT и AUTO ведутся отдельные команды.

При успешном завершении матча сервер записывает STATS для EXACT и, если этот матч выбран после завершения, для AUTO. Дедлайн отсчитывается от серверного времени записи, а длительность берётся из `statsSeconds`. Ручной STATS использует то же правило. Уже начатые итоги сохраняют дедлайн при изменении настройки. Старые завершения доступны для ручного показа. Истечение, скрытие и замена команды не возвращают предыдущее поколение. Канонический `postmatch` доступен в завершённом снимке, а эфир выводит его только при активном `statsPresentation`.

Атака идёт перед защитой. В каждой категории число страниц равно большему числу равных лидеров из двух команд. Короткий список удерживает последнего лидера, пустой показывает отсутствие результата. Категория с двумя пустыми списками пропускается. Длительность равна сохранённому интервалу, умноженному на сумму страниц.

ROSTER доступен при непустом ростере выбранного матча. POINT доступен только для текущего подтверждённого NEXT начатого матча с непустым составом. Оба показа выводят по пять игроков каждой команды на страницу, удерживают последнюю страницу более короткой стороны и истекают после одного прохода с интервалом, сохранённым при запуске. Снимок возвращает активную квитанцию в `playerPresentation`.

Скрытие автоматической фазы занимает новое поколение той же привязки. Снимок возвращает `suppressedPhase` (ROSTER или LINEUP), пока это поколение последнее и фаза совпадает. Следующая базовая фаза видна автоматически. При замене команды скрытия ручным показом, истечение или скрытие нового показа возвращает текущую базовую фазу.

После скрытия конечного показа, истечения или изменения входных данных показывается текущая базовая фаза. Ревизии журнала, составов и настроек защищают от возврата старого показа. AUTO также учитывает историю изменившихся матчей, которые могли вытеснить выбранный матч, включая удалённые. Для завершённого выбора изменения жизненного цикла других начатых матчей тоже требуют свежего показа. Чтение сохраняет состояние команд без изменений.
