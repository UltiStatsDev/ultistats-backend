# Показ лидеров в OBS

На защищённой странице `/obs-leaders.html` выберите AUTO или EXACT, обновите контекст и нажмите «Показать лидеров матча». Кнопка «Скрыть» относится к текущему активному поколению. Команды требуют HTTPS, OBS_ADMIN, текущих идентификаторов установки/аккаунта/сессии и CSRF.

## Контракт

- GET `/api/v1/obs/infographics/leaders/{matchId|auto}` возвращает `presentation` с `expectedInputRevision`, `expectedSettingsRevision`, `expectedGeneration`, `activeGeneration` и `canShow`. Оба поколения могут быть null. AUTO сохраняет оболочку `snapshot`. Последнее поколение остаётся основанием для следующей команды после истечения, скрытия или потери актуальности.
- POST `/api/v1/obs/infographics/presentations` принимает `binding` (EXACT или AUTO), `expectedMatchId`, три поля `expected*` из `presentation` и UUID `operationId`. Явный null `expectedGeneration` означает первый показ в этом контексте. Ответ 200 содержит `generation`, `matchId`, `startedAt`, `expiresAt` и `pageSeconds`.
- Повтор с тем же `operationId` и теми же полями возвращает исходный ответ даже после скрытия или истечения. Для нового показа прочитайте текущий контекст и создайте новый `operationId`. 409 означает конфликт входных данных, поколения, повторное использование идентификатора с другими полями или отсутствие положительных лидеров.
- DELETE `/api/v1/obs/infographics/presentations/{generation}` возвращает 204 для текущего поколения, в том числе при повторном скрытии. Старое поколение получает 409.

## Проекция эфира

В защищённом снимке и keyless preview поле `leaderPresentation` содержит актуальное поколение, абсолютные времена, интервал и зафиксированные списки обеих команд либо null. Ключ источника даёт доступ к чтению снимка. Для EXACT и AUTO ведутся отдельные команды.

Атака идёт перед защитой. В каждой категории число страниц равно большему числу равных лидеров из двух команд. Короткий список удерживает последнего лидера, пустой показывает отсутствие результата. Категория с двумя пустыми списками пропускается. Длительность равна сохранённому интервалу, умноженному на сумму страниц.

После скрытия, истечения или изменения входных данных показывается текущая базовая фаза. Ревизии журнала, составов и настроек защищают от возврата старого показа. AUTO также учитывает историю изменившихся матчей, которые могли вытеснить выбранный матч, включая удалённые. Для завершённого выбора изменения жизненного цикла других начатых матчей тоже требуют свежего показа. Чтение сохраняет состояние команд без изменений.
