Добавить в OBS

Добавьте Browser Source, вставьте ссылку. Размер: 1920 × 1080; фон страницы прозрачный. Перемещайте и масштабируйте источник средствами OBS. Новые события появляются сверху в выбранном углу.

Только доверенная сеть: страница и API без авторизации. Не публикуйте их в интернете. После перезагрузки история не проигрывается; при reconnect выводятся последние пропущенные события.
